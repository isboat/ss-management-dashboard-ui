## Development

The application requires Node 24 and npm 10. From the application directory:

```bash
cd src/ss-management-dashboard-ui-app
nvm use
npm ci
npm start
```

Run `npm run lint`, `npm test -- --watch=false`, `npm run build`, and
`npm run e2e` before submitting changes.
